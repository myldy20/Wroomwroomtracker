WROOMWROOM

A browser-first multi-engine tracker. Tap the grid directly, drag values, and switch musical contexts instead of driving a virtual gamepad.

WroomWroom Web controls

  • Tap/click a tracker cell to move focus there.
  • Drag horizontally to change the focused value. Phrase note pitch uses fine steps.
  • Double tap/click the focused cell, or press EDIT, to invoke its editor/action.
  • SONG / CHAIN / PHRASE / SOUND / MIX switch the actual tracker screen directly.
  • PLAY starts or toggles playback for the active tracker context. STOP always stops.
  • BACK uses the tracker's normal Opt/Back behavior. CLEAR performs the tracker's normal clear/reset action.
  • Desktop keyboard and gamepad input remain available; the web UI no longer requires them.

Projects and imported samples stay in browser-local storage unless you explicitly download a project file.
